# voice-clarity-acceptance

`voice-clarity-acceptance` 是面向公共建筑应急广播调试工程师和建筑声学验收审核员的语音可懂度验收工作台。系统把验收案范围、冻结测点计划、现场原始读数、区域判定、偏差整改、定向复测、人工审核和不可变凭据串成一个可追溯闭环。

服务由 Go 单进程提供原生 HTML、CSS、JavaScript 页面和同源 JSON API，不需要 Node 构建链。业务数据保存为带 `schemaVersion` 的本地 JSON 快照，审计事件写入只追加的摘要链日志；快照使用临时文件、`Sync` 和原子 `Rename` 提交，启动时会校验快照与审计序号、前序摘要和事件摘要。

## 构建

要求 Go 1.22 或更高版本。

```text
go build ./cmd/server
```

## 运行

标准启动命令：

```text
go run ./cmd/server -addr=127.0.0.1:19081 -data=./data/voice-clarity
```

浏览器访问 `http://127.0.0.1:19081/`。监听地址只接受回环地址和 1024 以上端口。也可以设置 `PORT` 为端口号，此时服务绑定 `127.0.0.1:<PORT>`；显式 `-addr` 参数优先于 `PORT` 生成的默认值。

工作台按以下顺序操作：创建验收案并登记多个区域阈值，保存基础范围后可复制、排序和批量维护区域；保存测点计划后先执行只读预检，再携带预检修订号和候选摘要冻结。开放轮次支持多测点批量提交，现场误录可在关轮前提交带原因的替代读数并保留历史证据；不通过时从区域判定明细中选择失败、无效或缺失测点登记偏差并进行定向复测。通过后由审核员批准或退回，退回事项保留结构化定位。批准会封存凭据，页面可重算业务快照摘要并查看审计链诊断报告。

案卷列表支持关键词、状态、排序和分页；计划保存会保留可对比、可恢复的修订快照。现场测量提供关轮质量门禁和差额分级复核，整改偏差可追加执行记录，审核退回事项可逐项关联本案证据解决。凭据页支持按完整凭据 ID 或递增序号精确检索，并沿用摘要和审计链核验。

## 测试与自检

运行全部单元测试和集成测试：

```text
go test ./...
```

运行有界自检：

```text
go run ./cmd/server -selfcheck -addr=127.0.0.1:19081
```

自检会使用临时数据目录，在配置的真实回环监听器上通过 HTTP 依次完成建案、冻结计划、两次读数提交、总体判定、审核批准、凭据校验和审计查询，然后自行关闭服务并删除临时数据。

## 数据文件

默认数据目录为 `data/voice-clarity`，主要文件包括：

- `snapshot.json`：已提交验收聚合、幂等结果、凭据序号和审计游标。
- `audit.jsonl`：只追加审计事件及其递增序号、前序摘要和当前摘要。

所有写命令都需要 `expectedVersion` 和 `idempotencyKey`。版本不一致会返回 `409 version_conflict`，同一个幂等键重放不会再次推进版本。
